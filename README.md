# 🛡️ Sangre Carbayona 2.0

Segunda versión de la web **Sangre Carbayona**, un proyecto en constante evolución para modernizar la página dedicada a la actualidad, historia y afición del **Real Oviedo**.

## 🛠️ Tecnologías utilizadas

Este proyecto está construido de forma sencilla utilizando:

- **HTML5:** Estructura de las páginas.
- **CSS3:** Diseño y maquetación.
- **JavaScript (Vanilla):** Lógica y minijuegos.

## 📂 Estructura del Proyecto

- `/css` - Estilos visuales.
- `/js` - Scripts de funcionamiento.
- `/fichas` - Datos de los jugadores.
- `/juegos` - Recursos de los minijuegos.
- `/generador` - Herramientas internas.
